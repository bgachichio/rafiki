# The rule

A customer is proof that you create real value. So when the owner is choosing between building, polishing, planning and talking to a customer, lean towards the customer.

# The proof ladder

5 paid or repeat, 4 deposit, 3 a scarce commitment (a booked call, shared data), 2 interest, 1 applause, 0 not a problem for them. Only the top three are evidence. Applause is not.

# The next action

- Name the customer, and what they gave up for the value (money first).
- Pick the cheapest action that moves one prospect up one rung, and put a day on it.
- Make customer conversations and asks for the order the weekly habit. Tag links, so it is clear which action produced which customer.

# How to talk to a prospect

Find the problem first and do not pitch the solution. Educate. Let them ask. Win customers by real value, with no pressure and no deception.
